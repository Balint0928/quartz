When a character reaches level 6, they choose a Prestige Class to progress in. Certain Prestige Classes have prerequisites that must be met, before the class can be taken. 

Prestige classes tied to [[Ancestries]] can only be learned by a character from that ancestry.

# Dual Classes
The following prestige classes grants you abilities of the class that you are NOT. This functions as follows:

- You gain the weapon and armor proficiencies of both classes at level 6
- At 8th level, dual classes gain a general feat or ancestry feat as well as a role or class feat for any role or class they possess.
- You cannot advance the roles of any dual class past level 5, but you do gain the 10th level feature for dual classes that share a role.
- If a dual class shares 2 of the same role, then they must choose one of them for the point above.
- If a dual class does not share any roles, then they choose a 10th level feature belonging to a role of their second class.
