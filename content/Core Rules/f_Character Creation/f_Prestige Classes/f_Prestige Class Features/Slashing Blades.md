You gain [[Weapon Mastery]] with the [[Scimitar]]. If you already have both the Mastery and the Special, Scimitars gain the following traits while you are wielding them:

- [[Light]]
- Deadly - Critical hits add an additional weapon die to the damage roll.
- Cut - Deals additional damage to the target equal to its [[Heft]] if the target has no armor or shield. (or 0 AV)
