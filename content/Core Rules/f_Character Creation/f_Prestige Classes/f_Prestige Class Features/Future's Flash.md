As an action you may select an enemy in combat and choose one of these action types: [[Attack Action]], Spellcasting, [[Dodge Action]], [[Dash Action]], [[Disengage Action]] or Skill check. If a the target performs one of these actions on its turn, you gain a [[Portent]] die. You may store this die only until the end of the current combat. A creature can only be affected by this ability once per combat.

*(A good way to avoid metagaming with this feature is, to write down the prediction on a piece of paper, and place it face down on the table.)*
