As an action, select an ally within 60 feet, that has been dead no longer than 1 minute. You lose access to your spirit(s) until you finish a [[Short Rest]]. That ally is brought back to life as if the spell Revivify was cast on them. You can use this feature once per [[Extended Rest]].
