You can concentrate on two concentration spells at the same time. You must still follow all game mechanics for those spells as normal. You have the following restrictions:

- If you are subjected to an effect that dispels magic, you lose both spells, instantly.

- You make concentration checks from disadvantage. This is an absolute effect.

- Each time you use this feature, and gain AP from casting the spells, increase the total AP gained by 2.
