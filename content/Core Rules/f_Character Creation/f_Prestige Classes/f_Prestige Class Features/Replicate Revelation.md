Whenever you succeed on a [[Martial Knowledge]] check and learn about a feature that the target creature possesses, you can expend a spell slot to copy that feature if it is possible for your character to use it (DM discretion). You keep the feature for up to 1 minute or until the end of the current combat encounter. You can only have one such feature at a time, and learning a new one replaces the previous. Each time you active or would benefit from the feature, you gain 1 AP. The following rules apply to replicated features:

**Range and Duration:**
- Any Action performed from the copy originates from you and has the same range as listed in the creature's action. If the Action has a lasting effect, you must concentrate on the effect as though it was a spell, and it lasts for either its original duration or 1 minute, whichever is shorter. You cannot use this feature to copy spellcasting.
**Attacks and Saves:**
- If a feature requires an attack roll to be made, or the target to make a saving throw, use your Spell Save DC and Spell Attack modifier for these.
**Damage:**
- Actions that deal damage deal an amount that equals 1d8 + 1d8 per Prestige Class level (Maximum 6d8).
