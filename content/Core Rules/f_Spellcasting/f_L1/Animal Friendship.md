# 1st Level

| Type         | Stat     |
| ------------ | -------- |
| Casting Time | Action   |
| Range        | 30 feet  |
| Components   | V, S, M  |
| Duration     | 24 hours |
Target a Beast that you can see within range. The target must succeed on a Wisdom saving throw or have the Charmed condition for the duration. It has advantage on the check if you or your allies are fighting it. If you or one of your allies deals damage to the target, the spells ends.

**Upcasting:** You can target one additional Beast for each spell slot level above 1.
