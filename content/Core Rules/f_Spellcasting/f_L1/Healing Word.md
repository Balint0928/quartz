# 1st Level

| Type         | Stat         |
| ------------ | ------------ |
| Casting Time | Bonus Action |
| Range        | 60 feet      |
| Components   | V            |
| Duration     | Instant      |
A creature of your choice that you can see within range regains Hit Points equal to 1d4 plus your spellcasting ability modifier.

**Upcasting:** The healing increases by 1d4 for each spell slot level above 1.
