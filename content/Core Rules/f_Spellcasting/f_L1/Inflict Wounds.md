# 1st Level

| Type         | Stat    |
| ------------ | ------- |
| Casting Time | Action  |
| Range        | Touch   |
| Components   | V, S    |
| Duration     | Instant |
A creature you touch makes a Constitution saving throw, taking 2d10 Necrotic damage on a failed save or half as much damage on a successful one.

**Upcasting:** The damage increases by 1d10 for each spell slot level above 1.
