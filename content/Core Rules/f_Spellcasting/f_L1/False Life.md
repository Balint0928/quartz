# 1st Level

| Type         | Stat    |
| ------------ | ------- |
| Casting Time | Action  |
| Range        | Self    |
| Components   | V, S, M |
| Duration     | Instant |
You gain 2d4+4 Temporary Hit Points.

**Upcasting:** You gain 5 additional Temporary Hit Points for each spell slot level above 1.
