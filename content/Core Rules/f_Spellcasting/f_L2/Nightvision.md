# 2nd Level

| Type         | Stat                     |
| ------------ | ------------------------ |
| Casting Time | Action                   |
| Range        | Touch                    |
| Components   | V, S, M (a dried carrot) |
| Duration     | 8 hours                  |
For the duration, a willing creature you touch gains Darkvision with a range of 60 feet.
