# 2nd Level

| Type         | Stat                            |
| ------------ | ------------------------------- |
| Casting Time | Action or 1 minute              |
| Range        | Touch                           |
| Components   | V, S, M (a small silver hammer) |
| Duration     | 1 hour                          |
You touch a nonmagical weapon. Until the spell ends, that weapon becomes a magical, [[Enchanted Item]] with a random, low-tier affix. The spell ends early if you cast it again.

If you cast this spell over 1 minute, you can choose the affix out of 3 random rolls.

**Using a Higher-Level Spell Slot:** Using at least a 3rd level slot allows for an extra low-tier affix. Using a 5th level slot allows for one of the affixes to be high-tier.
