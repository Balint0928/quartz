# 2nd Level

| Type         | Stat   |
| ------------ | ------ |
| Casting Time | Action |
| Range        | Touch  |
| Components   | V, S   |
| Duration     | 1 hour |
You touch a creature and end the Poisoned condition on it. For the duration, the target has Advantage on saving throws to avoid or end the Poisoned condition, and it has Resistance to Poison damage that equals your spellcasting modifier.
