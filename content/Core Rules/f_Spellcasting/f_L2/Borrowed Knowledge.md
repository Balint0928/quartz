# 2nd Level

| Type         | Stat                                  |
| ------------ | ------------------------------------- |
| Casting Time | Action                                |
| Range        | Self                                  |
| Components   | V, S, M (a book worth at least 25 gp) |
| Duration     | 1 hour                                |
You draw on knowledge from an otherworldly entity. Choose one skill in which you lack proficiency. For the spell's duration, you have proficiency in the chosen skill. The spell ends early if you cast it again.
