# Cantrip Level

| Type         | Stat    |
| ------------ | ------- |
| Casting Time | Action  |
| Range        | Touch   |
| Components   | V, S    |
| Duration     | Instant |
You touch a creature that is currently in the [[Dying]] state. The creature immediately becomes stable, as per a successful [[Stabilize Action]].
