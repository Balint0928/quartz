# Cantrip Level

| Type         | Stat     |
| ------------ | -------- |
| Casting Time | Action   |
| Range        | 120 feet |
| Components   | V, S     |
| Duration     | Instant  |
You hurl a mote of fire at a creature or an object within range. Make a ranged spell attack against the target. On a hit, the target takes 1d10 Fire damage. A flammable object hit by this spell starts to [[Burn]] if it isn't being worn or carried.

The fire damage increases to 2d10 at 5th level.
