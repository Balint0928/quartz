# Cantrip Level

| Type         | Stat       |
| ------------ | ---------- |
| Casting Time | Action     |
| Range        | Self       |
| Components   | S, M       |
| Duration     | 10 minutes |
You turn herbs, mud, and plant matter into a natural remedy. This natural remedy functions as a [[Healers Kit]], with 1 charge. If the remedy decomposes at the end of the duration naturally, or if you cast this spell again. A creature can only benefit from the health restoring function of a [[Healers Kit]], created this way, once per [[Long Rest]].

The amount of charges created at once increases to 2 at 5th level.
