# Cantrip Level

| Type         | Stat    |
| ------------ | ------- |
| Casting Time | Action  |
| Range        | Self    |
| Components   | V, S    |
| Duration     | Instant |
You channel dark powers to propel yourself towards your adversaries. You immediately take the [[Charge Action]], and you can use your spellcasting ability modifier instead of CON or DEX for determining the distance.
