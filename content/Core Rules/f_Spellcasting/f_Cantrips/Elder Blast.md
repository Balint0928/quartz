# Cantrip Level

| Type         | Stat    |
| ------------ | ------- |
| Casting Time | Action  |
| Range        | 120 ft. |
| Components   | V, S    |
| Duration     | Instant |
A beam of dazzling color streaks toward a creature within range. Make a ranged spell attack against the target. On a hit, the target takes 2d4 damage. To determine the damage type, choose one of the rolled d4s and the number rolled on that d4 correlates to a damage type.

| d4  | Damage Type |
| --- | ----------- |
| 1   | Acid        |
| 2   | Lightning   |
| 3   | Cold        |
| 4   | Poison      |

The spell creates one more beam when you reach 5th character level. You can direct the beams at the same target or at different ones. Make a separate attack roll for each beam.
