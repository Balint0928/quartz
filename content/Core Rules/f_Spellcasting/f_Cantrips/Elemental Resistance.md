# Cantrip Level

| Type         | Stat                          |
| ------------ | ----------------------------- |
| Casting Time | Action                        |
| Range        | Touch                         |
| Components   | V, S                          |
| Duration     | Concentration, up to 1 minute |
You touch a willing creature and choose a damage type: Acid, Bludgeoning, Cold, Fire, Lightning, Necrotic, Piercing, Poison, Radiant, Slashing, or Thunder. The creature gains 1d4 resistance against that damage type (the 1d4 is rolled each time the resistance triggers). A creature can benefit from this spell only once per turn.
