# Cantrip Level

| Type         | Stat    |
| ------------ | ------- |
| Casting Time | Action  |
| Range        | 120 ft. |
| Components   | V, S    |
| Duration     | Instant |
A beam of scorching hellfire streaks toward a creature within range. Make a ranged spell attack against the target. On a hit, the target takes 1d10 fire damage. On a critical hit, the target starts to [[Burn]].

The spell creates one more beam when you reach 5th character level. You can direct the beams at the same target or at different ones. Make a separate attack roll for each beam.
