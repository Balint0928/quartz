# Cantrip

| Type         | Stat                              |
| ------------ | --------------------------------- |
| Casting Time | Action                            |
| Range        | Touch                             |
| Components   | V, S                              |
| Duration     | **Concentration**, up to 1 minute |
You touch one willing creature. Once before the spell ends, the target can roll a d4 and add the number rolled to one ability check of its choice. It can roll the die before or after making the ability check. The spell then ends. A creature can only benefit from this spell once every hour.
