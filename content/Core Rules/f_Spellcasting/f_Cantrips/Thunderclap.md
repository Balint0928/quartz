# Cantrip Level

| Type         | Stat    |
| ------------ | ------- |
| Casting Time | Action  |
| Range        | Self    |
| Components   | S       |
| Duration     | Instant |
Each creature within 5 feet of you must succeed on a Constitution saving throw or take 1d6 Thunder damage. The spell's thunderous sound can be heard up to 100 feet away.

The Thunder damage increases to 2d6 at 5th level.
