# Cantrip Level

| Type         | Stat    |
| ------------ | ------- |
| Casting Time | Action  |
| Range        | 120 ft. |
| Components   | V, S    |
| Duration     | Instant |
A beam of brilliant light streaks toward a creature within range. Make a ranged spell attack against the target. On a hit, the target takes 1d8 Radiant damage. If another source of Radiant damage is dealt to the target before the start of your next turn, it takes an extra 1d6 Radiant damage.

The spell creates one more beam when you reach 5th character level. You can direct the beams at the same target or at different ones. Make a separate attack roll for each beam.
