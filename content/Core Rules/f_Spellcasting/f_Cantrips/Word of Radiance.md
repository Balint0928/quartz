# Cantrip Level

| Type         | Stat    |
| ------------ | ------- |
| Casting Time | Action  |
| Range        | Self    |
| Components   | V, M    |
| Duration     | Instant |
Burning radiance erupts from you in a 5-foot radius. Each creature of your choice that you can see in it must succeed on a Constitution saving throw or take 1d6 Radiant damage.

The Radiant damage increases to 2d6 at 5th level.
