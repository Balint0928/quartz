# Cantrip Level

| Type         | Stat         |
| ------------ | ------------ |
| Casting Time | Bonus Action |
| Range        | Self         |
| Components   | V, S, M      |
| Duration     | 1 minute     |
 [[Club]] or [[Quarterstaff]] you are holding is imbued with nature's power. For the duration, you can use your spellcasting ability instead of Strength for the attack and damage rolls of melee attacks using that weapon, and the weapon's damage die becomes a d8. The spell ends early if you cast it again or if you let go of the weapon.

The damage die changes to 1d10 at 5th level.
